# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2024-12-26

### Added
- New Stitch UI design system implementation
- Consistent color palette and typography across all screens
- Improved component library (Card, Button, BackHeader, Icon)
- Enhanced visual feedback and animations

### Changed
- Complete UI redesign following Stitch wireframes
- Updated HomeScreen with new layout and character display
- Redesigned MissionScreen with better progress visualization
- Improved RecordScreen with cleaner data presentation
- Enhanced ProfileScreen with organized sections

## [1.0.4] - 2024-12-25

### Added
- Reward system with popup notifications
- Ranking feature for gamification
- Daily missions with progress tracking
- Character growth system

### Changed
- Merged Character tab into HomeScreen
- Improved mission completion flow

## [1.0.3] - 2024-12-24

### Added
- Weekly health report generation
- Lab section for health data visualization
- HealthKit integration for iOS
- Real-time health data sync

### Changed
- Enhanced health data display
- Improved report formatting

## [1.0.2] - 2024-12-23

### Added
- AI-powered health chat using Gemini
- Character companion with speech bubbles
- Personalized health advice

### Changed
- Improved chat UI and response handling
- Enhanced character animations

## [1.0.1] - 2024-12-22

### Added
- Login screen with Supabase authentication
- Health survey onboarding flow
- Personalized mission generation based on survey

### Fixed
- Authentication flow issues
- Session persistence

## [1.0.0] - 2024-12-21

### Added
- Initial release
- Daily condition check feature
- AI mission generation with Gemini
- Mission completion and auto-growth system
- Store tab with product browsing
- AI product recommendations
- Daily state reset functionality
- Core navigation structure
- Zustand state management
- Supabase backend integration
